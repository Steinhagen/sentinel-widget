# Screenshots

Add real screenshots of the widget here before submitting it to KDE Store.
Recommended:

- `dark.png` — full dashboard in a dark Plasma color scheme.
- `light.png` — full dashboard in a light Plasma color scheme.
- `filters.png` — table with an active filter and the severity chips.

Use the current build and real scan data where possible. Avoid screenshots that
contain private hostnames, package paths or other local information.
