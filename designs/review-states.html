Cum afișăm „de verificat” și false pozitivele

Cinci direcții pentru coloana de triaj. În toate, rândurile false pozitive sunt vizibile pentru că setarea Verdicturi de triaj este oprită; rândurile confirmate nu primesc niciun marcaj. Aceleași date: network 3.2.8.0 (de verificat), setuptools 65.5.1 (fals pozitiv), brotli 1.2.1 (confirmat).

De verificat — triajul nu a putut confirma potrivirea Fals pozitiv — ascuns când setarea este pornită Confirmat — fără marcaj
Recomandarea mea: V1 + bara din V4. V1 păstrează coloana explicită și sortabilă, iar bara din V4 face vizibilă starea setării și oferă un singur click pentru „arată / ascunde false pozitive”. Dacă prioritatea este lățimea maximă pentru pachet și origine, alege V3.
